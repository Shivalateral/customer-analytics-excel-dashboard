# 📊 Customer Analytics Dashboard using Microsoft Excel

## 📌 Project Overview

This project presents an interactive **Customer Analytics Dashboard** developed in **Microsoft Excel** to analyze customer data and generate meaningful business insights. The dashboard leverages **Pivot Tables**, **Pivot Charts**, and **Excel formulas** to summarize customer information into key performance indicators (KPIs) and visual reports.

## 🎯 Project Objectives

- Analyze customer demographic and financial data.
- Build an interactive Excel dashboard.
- Create KPI cards for quick business insights.
- Visualize customer trends using Pivot Charts.
- Demonstrate Excel data analysis and reporting skills.
